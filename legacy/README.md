# Legacy Archive

This directory contains historical code, previous experiment outputs, archived
papers, and superseded web/tooling implementations.

Active code lives in:

- `src/` for Python packages
- `tsl_web/` for the Flask web translator
- `colab/` for current Colab notebooks
- root-level `*.py` files only as compatibility shims

Do not add new generated outputs, dependency folders, cache directories, or
browser profiles here. Keep new source changes in the active packages unless
they are intentionally preserving an old workflow.
