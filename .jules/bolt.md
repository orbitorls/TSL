## 2024-05-24 - Pandas Vectorization in Feature Extraction
**Learning:** In the TSL-51 pipeline, feature extraction iterates through hundreds of potentially missing dataframe columns (up to 478 face landmarks * 3 axes). Iterative `safe_mean()` checks on these columns created a massive CPU bottleneck (~1.03s per DataFrame extraction). Using `.mean(numeric_only=True).fillna(0.0).to_dict()` on a column intersection list handles NaNs identically while reducing loop operations and allocations drastically.
**Action:** When working with large Pandas DataFrames in feature extraction or real-time pipelines, avoid inner-loop iterations over DataFrame columns. Use Pandas vectorized methods to compute aggregates across columns simultaneously, then map the results into pre-allocated NumPy arrays.
