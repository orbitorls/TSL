## 2024-07-08 - Feature Extraction Regression via List Unification
**Learning:** When optimizing iterative dictionary/DataFrame extraction into vectorized operations via column lists, the exact order in which columns were originally appended dictates the structural layout of the ML features. Unifying loops can inadvertently shuffle this order, silently breaking downstream models. `_build_column_list` truncated to 1596, meaning 90 trailing face landmarks were truncated for the 'full' level, maintaining a specific index-to-feature mapping.
**Action:** When replacing iterative appends with a mapping based on a pre-built column list, write a strict comparison script to assert that `old_function_results == new_function_results` for the *exact same data* across all valid configurations *before* pushing code.
