## 2025-02-27 - Vectorizing Pandas Column Extraction Operations
**Learning:** In the TSL feature extraction layer, dynamically building feature vectors from Pandas DataFrames by iterating over expected columns with `if col in df.columns:` logic and appending results scalar-by-scalar introduces significant Python loop overhead. For operations invoked thousands of times during inference, scalar fallback methods like `safe_mean(lm_df[col])` become major bottlenecks.
**Action:** When extracting sequences or feature sets from Pandas into NumPy arrays, avoid explicit column iterations. Instead, use `available_cols = lm_df.columns.intersection(expected_cols)` and apply bulk assignment `np_arr[:, indices] = lm_df[available_cols].to_numpy()` or vectorized reduction `lm_df[available_cols].mean().to_dict()` to achieve an order of magnitude (> 10-20x) speedup.
