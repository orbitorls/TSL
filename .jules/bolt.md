## 2024-07-26 - Vectorizing feature extraction Pandas mean operations
**Learning:** In Pandas, extracting a single feature vector from a dataframe of landmarks frame-by-frame using iterative `.mean(skipna=True)` on single series (`lm_df[col].mean()`) is extremely slow due to the overhead of Pandas Series operations inside a Python loop (takes ~0.8s for 100 iterations of 162 columns).
**Action:** Replace iterative series operations with bulk dataframe vectorized operations `lm_df[available_cols].mean(numeric_only=True).fillna(0.0).to_dict()`. Map the resulting dictionary back to a list in the required column order using a simple Python list comprehension `[means.get(col, 0.0) for col in cols]`. This pattern is 7-18x faster while maintaining exact output parity and safely handling missing columns.
