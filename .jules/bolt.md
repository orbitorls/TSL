## 2024-05-18 - Pandas Data Extraction Performance Over Iteration
**Learning:** Extracting data from Pandas DataFrames iteratively over each column (e.g. `for col in cols: val = df[col].mean()`) is a huge performance bottleneck in this codebase, especially when performing sequence feature extraction where this is done for thousands of samples. Iterative lookup has large overhead in pandas compared to vectorized operations.
**Action:** When calculating statistics like mean across numerous columns, use vectorized operations such as `df[cols].mean(numeric_only=True).fillna(0.0).to_dict()`. When extracting array sequences, calculate the list of mapped valid column indices upfront and use `df[valid_cols].to_numpy()` in bulk to drastically speed up processing (~8x-15x faster).
