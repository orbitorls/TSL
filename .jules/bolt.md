## 2025-01-08 - Fast landmark feature extraction using Pandas and static keys
**Learning:** In standard pipelines, iterating row-by-row on dataframes (`safe_mean(lm_df[col])`) or building dictionary lists from frames block-by-block with multiple iterations and f-string evaluations has significant overhead in Python.
**Action:** When extracting multiple features (e.g., from dicts to arrays or computing column means), pre-compute keys statically (`_BASIC_KEYS = [...]`) for mapping from dictionaries, and use vectorized DataFrame aggregations (`lm_df[available_cols].mean(numeric_only=True).fillna(0.0).to_dict()`) instead of repeated `Series.mean()` calls. This can speed up feature extraction substantially (e.g. 10x faster for DataFrame operations, ~3x for dictionary conversions).
