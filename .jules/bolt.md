## 2024-07-01 - Vectorized Feature Extraction Speedup
**Learning:** In PyTorch/Machine Learning pipelines where feature extraction occurs dynamically over Pandas DataFrames, iterating over hundreds of columns calling `.mean()` individually is a severe bottleneck. The overhead of Pandas Series operations inside a Python loop can dominate the extraction time, especially for high-dimensional feature levels like 'full' (1596 dims) and 'face' (1434 dims).
**Action:** Replace iterative Pandas column lookups with vectorized block operations: select multiple columns via `.intersection()`, calculate all means simultaneously using `.mean(numeric_only=True)`, replace missing data using `.fillna(0.0)`, and map results back to a dict for instant ordered NumPy array population. This yields ~10x speedup during feature extraction and preserves fallback behavior identical to iterative handling.
